# Rapport Typst - Utilisation

## Fichier principal

- `docs/final_report/RAPPORT_ACADEMIQUE_FINAL.typ`

## Compilation PDF

Apres installation de Typst:

```powershell
typst compile docs/final_report/RAPPORT_ACADEMIQUE_FINAL.typ docs/final_report/RAPPORT_ACADEMIQUE_FINAL.pdf
```

## Notes

- Le fichier utilise des images dans `docs/final_report/assets`.
- Si la police `New Computer Modern` n'est pas disponible, Typst prendra une
  police de remplacement automatiquement.
